What I Learned About forEach and map

  

    I learned that forEach runs a function once for every item in an array,
    but it does not collect the return values. map also runs a function for
    every item, but it collects each return value into a new array.
  






  
What I Learned About Callbacks

  

    I learned that a callback is a function passed to something else to run
    when it is needed. I used callbacks with forEach, map, addEventListener,
    and fetch to process records, respond to clicks, and work with data that
    arrives later.
