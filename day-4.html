What I learned About Return Values

I learned that console.log prints a value for me to see, but return sends the value back to the code that called the function. That return value can then be stored in a variable or placed on the page.

What I Learned About Undefined

When summarize printed the sentence instead of returning it, the sentence appeared in the console but the page received undefined. Changing the function back to return sent the sentence to output.textContent correctly.
